## Modules share values and helpers by name

`exposing` may now name a value and a helper (ADR-0074/0075), so a limit a rule is written against,
a representative record examples are stated with, and a rule written as a helper are written once
and shared instead of restated in every module that needs them. A module no longer has to import a
whole record just to state a rule against it.

A value keeps one executable home, the module that declares it, and another module reaches it
through a published `$Values` entry rather than a copy of its body; a constant is written as its
literal wherever it is read. A non-recursive published helper is expanded at the reader's call
sites, and a recursive one travels under the declaring module's identity.

## Division is exact

`/` answers an exact `Rational` quotient (ADR-0116/0117). `Int / Int`, `Decimal / Decimal` and
`Rational / Rational` all come to a `Rational`, so `-1 / 2` in `guard y < -1 / 2 * x + 30` is no
longer nought, and the reasoning that reads a comparison's coefficients keeps them exact rather
than rounding. `1m == 2 / 2` is true.

## Compatibility

- `/` answers a `Rational`. `Int / Int` used to truncate toward zero and `Decimal / Decimal` to
  round. A truncated quotient is written `Int.truncatingDivide`, which `Int.divide` was renamed to,
  and a rounded one `Decimal.divide` with its scale and rounding mode.
- `String` measures in Unicode code points end to end (ADR-0096). `length`, `substring`, `toChars`
  and the rest agree on one unit, text is canonicalized to NFC at a decoder's string leaf and at a
  source literal, and `String.length` becomes O(n).
- A `Decimal` writes its amount rather than its scale, since `1.0` and `1.00` are one member of a
  `Set` by the time an encoder sees it, and a `Set`'s array is written in ascending order of its
  members' external representations, not insertion order or a hash bucket's (ADR-0094).
- The default Jackson mapper no longer accepts a JSON number with a fraction as a `Decimal`, a
  scaled `BigDecimal`'s integer encoding, or a `java.sql` date.

## Other changes

- `trim`, `words`, `lowercase` and `uppercase` are pinned to Unicode 18.0's own tables, independent
  of the JVM's locale or version (ADR-0118/0119).
- Boundary constraints (an invariant clause, `unique`, a map's size) are answered by the checker
  rather than assembled by codegen from a list. `unique`'s duplicate check reads Souther's own
  equality instead of the JVM's `HashSet`, so a `Decimal` or `Rational` where the two disagree is
  reported under the right diagnostic code.
- A temporal's text has its own grammar and domain, checked by arithmetic rather than by
  `java.time` or by whichever Raoh version is linked.
- A `Decimal` held at an extreme scale is written in exponent notation past a fixed digit threshold
  wherever it is written for a reader, instead of being spelled out in full.

The decisions behind these changes are ADR-0074, 0075, 0094, 0096 and 0116 to 0119, indexed in
[`docs/adr/README.md`](https://github.com/souther-lang/souther/blob/v0.3.0/docs/adr/README.md).
