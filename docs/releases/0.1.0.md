## The first release

Souther is a small JVM language for business rules that stay true: what a value may be, which states
follow which, and what each decision answers. The rules are written once, as `data` and `behavior`,
and compile to Java types that keep the distinctions the model made. The examples that describe a
behavior are part of the language: an `example` is evaluated while the model compiles, and
`souther examples` measures what those examples cover, saying what a question is still open on
where it cannot answer.

The [README](https://github.com/souther-lang/souther/blob/v0.1.0/README.md) starts with an
example, and [`specification.adoc`](https://github.com/souther-lang/souther/blob/v0.1.0/specification.adoc)
is the language.

## Since 0.1.0-rc5

- What a program states about its inputs is read relationally. The declarations reaching a
  behavior's input are asked through one boundary in that input's own paths and forms (ADR-0110),
  and a position that admits a choice across positions is read as a union of products where the
  expansion is small enough and as the hull otherwise (ADR-0107). Two fields at five together that
  sum to ten no longer draw a border on a quantity the model never reaches.
- Which decisions settle one value together is read off the body (ADR-0108). An outcome is a path
  to a value and carries what the value is (ADR-0109), so an operator that stops as soon as its
  answer is settled is read as the paths it has, and an arm no row reaches is told apart from an arm
  nothing can be said about.
- A behavior taking a sum is measured on more than the one axis the sum states. Refinements are
  part of the typed path, and coverage and generation share one merge, so the combinations counted
  and the rows offered cannot come apart (ADR-0114).
- A rule written about an element of a sequence, about a total a `fold` or `List.sum` comes to, or
  about a number a construction wrote, is measured where it is written. Where a reading cannot come
  to a line, the report says which rule went unread and why.
- Budgets are imposed where combinatorial or generative work is performed, not as a limit on the
  number of axes (ADR-0113).
- A program Souther accepts is one the JVM can emit (ADR-0115). A data with more fields than a JVM
  constructor can take is refused to the author with the machine's rule named.
- Every `decimal.*` operation converts exactly and turns a host failure into the result or abort
  the operation states, rather than dividing silently wrong (ADR-0112).
- An environment answers with the value a name denotes (ADR-0111), which puts
  `let v = t.value + 10` back into the rules a measure reads.
- `souther lsp` serves the language server from the same command line as the compiler, and the
  server answers more of an editor's questions from what the declarations already say.

The decisions are indexed in
[`docs/adr/README.md`](https://github.com/souther-lang/souther/blob/v0.1.0/docs/adr/README.md).
