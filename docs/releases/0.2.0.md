## Souther on Windows

The release carries Windows distributions: `souther-0.2.0-windows-x64.zip`, an application image
with `souther.exe` and its own Java runtime, and `souther-0.2.0-windows-x64-nojdk.zip`, the jar with
a `souther.cmd` launcher for a machine that already has Java. `install.ps1` downloads one, checks
it against `SHA256SUMS`, and puts the command on the path.

## A report says what it could not decide

A limit of this compiler is no longer reported as an answer about the model. A search budget's
refusal and an enumerator's incompleteness are kept apart, a reading that is absent is kept as
absent rather than reported as a search that found nothing, and an offer short of the rules is
said as that rather than as every value being refused. An open question carries what it is open
on, and a choice says what it left open: every case an answer leaves open is searched before a row
is settled, rather than one case being chosen before the alternatives were observed.

Every surface of `souther examples` reads one obligation account. A report says which half of a
boundary a measure went without and where a plan stopped short of the value.

## Other changes

- What a reading asks of a declaration is asked of the form that declaration publishes, not of the
  tree it was written as. A clause is read where it was expanded, and the rules governing a
  declaration are asked for by name in one representation.
- A comparison is read once, and what it placed is what every later reader answers from. A number
  stays on its own order once a rule has named it, a range is read against the order it is a range
  of, and an order with a hole in it carries the hole beside its ends.
- A position's measures are held under the position. Each is measured at every number its rules
  name, and what a position admits is narrowed by the rules about the numbers taken of it.
- A behavior owes a case of an input at a class only where it has the position, and the conditions
  the adequacy schema states are applied rather than only described.
- A diagnostic lands on what the author wrote: on the token rather than the line, on the part of
  the clause the author wrote, and on the choice by name.
- The language server works out a module's parameters once per revision rather than for every
  request, asks a code action of one compilation, and says where a repair goes.
- The repository's sources are parsed once rather than once per rule that asks, and a declaration
  is read once for every question that reaches it.
- `<?>` is read as a row whose answer is owed, and the bare name `row` is reserved for a row. A
  behavior stood in for by more than one fake block is refused, and a fixture's reads are typed by
  what their bindings hold.

No architecture decision was added in this release. ADR-0021, 0052, 0077, 0086, 0090, 0100, 0102,
0106, 0107, 0110 and 0111 were amended where the mechanism they describe moved, and
[`docs/adr/README.md`](https://github.com/souther-lang/souther/blob/v0.2.0/docs/adr/README.md)
indexes them.
